
SIEM Log Investigation – Splunk

Project Overview

This project demonstrates hands-on Security Information and Event Management (SIEM) investigation using Splunk and Windows event logs.

The objective was to explore authentication activity, identify suspicious login patterns, investigate security events, and practise basic threat-hunting techniques.

Objectives

- Understand how security logs are collected and analysed.
- Investigate failed and successful login activity.
- Identify unusual authentication patterns.
- Examine suspicious IP addresses and event activity.
- Develop Splunk search queries for security investigations.
- Practise basic threat hunting and event analysis.

Tools and Technologies

- Splunk
- Windows Event Logs
- SPL (Search Processing Language)
- Security log analysis

Investigation Areas


Authentication events | Failed and successful login activity 
Login patterns | Repeated or unusual authentication attempts
Source IP analysis | Investigating IP addresses in available logs
Security events | Reviewing relevant Windows security events
Threat hunting | Searching for potentially suspicious activity

Methodology

1. Reviewed the available log data.
2. Used Splunk searches to filter and examine relevant events.
3. Investigated authentication patterns and security-related activity.
4. Reviewed search results and identified notable observations.
5. Documented findings and supporting evidence.

Evidence

Screenshots and relevant investigation results are maintained in the project folders.

Key Skills Practised

- SIEM monitoring
- Log analysis
- Splunk SPL searches
- Authentication investigation
- Basic threat hunting
- Security event analysis

Project Limitations

This was a personal hands-on lab using available log data. It was not a live enterprise SOC environment. Findings are limited to the events and data available in the lab.

Learning Outcome

Gained practical exposure to analysing security logs, investigating authentication activity, constructing Splunk searches, and understanding how SIEM tools support security monitoring and investigation.
